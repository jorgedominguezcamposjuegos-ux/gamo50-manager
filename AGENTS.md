# Mantenimiento de Gamo 50

Antes de dar altas, bajas o cambiar la distribución del grupo, leer
`docs/MANTENIMIENTO_PLANTILLA.md`. Recoge el procedimiento y las regresiones
detectadas en el Control de salida, confirmadas por el usuario el 17/10/2026.

Trabajar dentro de `webapp`. Preservar cambios locales y archivos ajenos a la
tarea. No interpretar una petición de análisis como autorización para cambiar
Firebase o publicar. Para commits, subidas y despliegues, atender al alcance
autorizado por el usuario en la conversación.
